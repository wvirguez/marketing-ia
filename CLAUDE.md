# Claude Code repository entry point

The imported `AGENTS.md` is the shared source of repository-wide rules for
Claude Code and Codex, including current project status. Read `apps/web/CLAUDE.md`
and `apps/web/AGENTS.md` before frontend work. Keep frontend-specific
instructions there. Read `docs/backend/` (BACKEND-01 architecture and domain
model) before any backend work. Any future `apps/api` implementation must
follow the shared root rules and add its own scoped instructions when its
implementation is requested.
